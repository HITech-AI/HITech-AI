先学会 GitHub 协作

GitHub 是社团开源协作的底座。第一场社团活动就是《GitHub 与 AI Agent 入门》，从这里起步，后续协作就有了共同语言。

新手必学的 GitHub 操作

  • 注册与登录：到 github.com 注册，昵称建议用真名或常用 ID。
  • 搜索项目：在搜索框输入关键词，按 Stars 排序找热门项目。学会读 README——它是项目的说明书。
  • 找 Releases：项目的正式发布版本在 Releases 页面下载，不要直接下载源码压缩包。
  • 基本操作：创建仓库（New Repository）、提交（commit）、推送（push）。这些在首场活动会手把手教。
  • 进阶：Markdown 写作、提 Issue（报问题/提建议）、发起 Pull Request（PR，给别人的项目贡献代码）、分支管理。
AI Agent 是你的 GitHub 助手：注册时不知道怎么填资料？让 AI 帮你写；写 commit 说明不知道怎么措辞？让 AI 帮你写规范提交信息；push 报错了？把错误信息贴给 AI，它会帮你定位原因。这是社团首场活动的核心思路。

参与开源贡献流程

HITech-AI 是社团的 GitHub 开源组织，以 docs（文档库）与 projects（项目库）沉淀学习与项目成果。遵循"仓库固定、目录扩展"原则。

Fork → PR 协作流程

  1. Fork：在 GitHub 上找到 HITech-AI 组织下的目标仓库，点击 "Fork" 把它复制到你自己的账号下。
  2. 克隆到本地：把你 Fork 的仓库 clone 到电脑上，新建一个分支（如 add-xxx），在分支上修改。
  3. 提交改动：写完修改后 commit 并 push 到你自己的 Fork 仓库。提交信息建议用 Conventional Commits 格式（如 docs: add resource card for Python）。
  4. 发起 Pull Request：在 GitHub 上点击 "New Pull Request"，选择你的分支 → 社团仓库主分支。写清楚你改了什么、为什么改。
  5. Review 与合并：社团维护者会 review 你的 PR，提出修改意见（如有），你修改后再次提交。通过后合并到主仓库。

哪些内容适合贡献

  • 补充文档：在 docs 仓库里添加一篇学习笔记、一张资源卡、一份活动记录。
  • 修正链接：发现页面上的链接打不开、或指向过时内容，直接提 PR 修正。
  • 提 Issue：发现问题或有新想法，先开一个 Issue 讨论，不要直接改代码。
  • 参与项目开发：在 projects 仓库中认领 Issue，参与 HIT-CampusAI 等项目的开发。

联系老师、学长与合作

怎么联系老师 / 课题组

  • 先做功课：看学院主页和教师介绍，了解老师的研究方向和近期发表，不要海投邮件。
  • 准备简短自我介绍：姓名、年级、专业、目前在学什么、对老师哪个方向感兴趣、想参与什么（不要超过 200 字）。
  • 说明来意：是想旁听组会、申请本科生科研、还是只是请教方向？说清楚你想要什么。
  • 通过社团渠道：实践部负责对外联系和校企对接，社团可以以组织名义帮你牵线，比个人单打独斗更有效。

怎么找学长

  • 部门活动：技术部的双周技术分享和 Agent 训练营里，带活动的骨干就是学长。
  • 研讨部：研讨部的议题讨论中，主持和实证演示人都是有相关经验的学长，可以直接交流。
  • 社团答疑群：在群里直接提问，学长和骨干会回复。问问题时尽量把上下文说清楚（你在做什么、卡在哪、试过什么）。

在社团内找搭子组队

  • 按学习路线组队：在 学习路线里选同一条路线的人，天然有共同进度。在群里说一声"我在走 XX 路线第 X 周，找搭子"。
  • 加入或发起项目：在 projects 项目库里看有哪些项目正在招人，或自己发起一个项目提案。
  • 黑客松与竞赛：学期末内部黑客松是最好的组队机会——现场临时组队，48 小时内做一个作品。外部比赛由实践部核实通知后组织报名。

外部组织合作模式

社团与外部组织的合作由实践部牵头对接，技术部准备内容和代表作品，具体模式如下：

合作方
Datawhale · AI+X 高校行
合作内容：Datawhale 提供教程、SOP、物料和嘉宾支持；社团提供场地、组织人员和本地宣传。我们已对接并进入发起者群，首期落地《AI 新手村》高校行活动。
社员收获：免费参加 AI 入门实践活动、获得 Datawhale 证书、可免费学习 36 门 AI 入门课。
合作方
企业开源组织（如百度飞桨领航团）
合作内容：借助企业开源组织的免费课程、技术专家和硬件资源联合开展活动。从分享与项目点评开始积累支持。
社员收获：接触企业工程师、获得官方课程资源、有机会参加企业活动和比赛。
合作方
开源社区（GitHub / Hugging Face 等）
合作内容：以社团开源组织 HITech-AI 为载体，参与开源社区的贡献活动。我们的项目（HIT-CampusAI 等）开源在 GitHub 上，接受外部贡献。
社员收获：获得真实的开源协作经验、积累 GitHub 贡献记录、为简历加分。
