先学会 GitHub 协作

GitHub 是社团开源协作的底座。第一场社团活动就是《GitHub 与 AI Agent 入门》，从这里起步，后续协作就有了共同语言。
【待补充】GitHub 入门要点

建议给出：注册与登录、搜索项目、读 README、找 Releases；进阶的 Markdown、Issue、Pull Request 与基本分支操作。

可链接到社团 docs 文档库 里的教学资料。

参与开源贡献

HITech-AI 是社团的 GitHub 开源组织，以 docs（文档库）与 projects（项目库）沉淀学习与项目成果。遵循"仓库固定、目录扩展"原则。

【待补充】参与开源流程

写明：Fork → 新建分支 → 提交改动 → Pull Request 的基本流程；Conventional Commits 提交规范；哪些内容适合贡献（补充文档、修正链接、提 issue、参与项目开发）。

见仓库 CONTRIBUTING 与 CODE_OF_CONDUCT。

联系老师、学长与合作

【待补充】联系方法

建议给出：

  • 怎么联系老师：看学院主页 / 课题组介绍、准备一份简短的自我介绍、说明想参与什么。
  • 怎么找学长：通过部门活动、研讨部调研、社团答疑群对接。
  • 对外合作：实践部对接企业（如 Datawhale、百度飞桨）与开源社区，把合作机会沉淀在这里。
