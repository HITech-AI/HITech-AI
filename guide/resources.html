书籍

书名作者说明
《机器学习》（西瓜书）周志华国内机器学习经典教材，理论体系完整。适合配合课程读，不建议零基础自学。
《动手学深度学习》李沐 等DL 实践首选，有 PyTorch 版本，代码可运行。免费在线版：zh.d2l.ai
《深度学习》（花书）Goodfellow 等深度学习理论"圣经"，适合有一定基础后深入读。
《统计学习方法》李航简洁精炼的机器学习数学教材，适合补数学基础。

教程与操作指南

  • Python 入门：廖雪峰 Python 教程（中文）、Python 官方教程（中文版）。
  • GitHub 入门：GitHub 官方《Hello World》指南、社团首场活动《GitHub 与 AI Agent 入门》讲义。
  • Agent / Skill 教程：hello-agents、Datawhale 智能体与自动化搭建课。
  • RAG 实践：Hugging Face 关于 RAG 的官方教程、LangChain / LlamaIndex 官方文档。
  • PyTorch 入门：PyTorch 官方教程。

博客与观点

  • Hugging Face 博客：最新模型发布、教程和技术解读，质量高，更新勤。
  • Anthropic Research：Claude 团队的研究博客，关于 Agent 和对齐的思考很深入。
  • OpenAI Research：GPT 系列的技术报告和研究博客。
  • GitHub Blog：GitHub 官方博客，关于开发工具和开源协作的实践。
  • 社团成员博客：见 社区动态，成员的学习总结、项目复盘和方法论思考。

工具与平台

代码与协作
GitHub
代码托管和开源协作的底座。社团开源组织：HITech-AI。
模型与数据集
Hugging Face
最大的模型和数据集开源平台。可以在线试用模型、下载预训练模型、找数据集。huggingface.co
在线编程
Google Colab
免费在线 Jupyter Notebook，提供 GPU 资源，不用本地配置环境就能跑深度学习代码。colab.research.google.com
AI 对话工具
豆包 / DeepSeek / Kimi
日常对话、写文案、解报错、查资料。任选一个常用即可。
AI 编程助手
Cursor / VS Code Copilot
在编辑器里直接用 AI 写代码、解报错、生成注释。
论文检索
arXiv / Semantic Scholar
找论文和读论文的入口。详见 读论文。
