部门定位

技术部是社团的"工程引擎"。我们把 AI 从概念变成可运行的项目，把原理讲清楚、把工具用顺手，让社员不只是"听说过 AI"，而是真的能上手做东西。

部门关键词：原理科普 · 工具教学 · 项目开发 · 技术答疑

核心职责

技术分享
AI 原理科普与工具教学
组织技术分享会，把大模型、Agent、RAG 等概念讲清楚，带大家用起来。
项目开发
社团门面项目维护
主导 HIT-CampusAI 等开源项目的开发、迭代与维护，是社团代码的主阵地。
技术支撑
活动技术保障
为社团活动提供技术演示、环境搭建、现场答疑（如 Agent 搭建演示、GitHub 教学）。
开源协作
GitHub 组织运营
维护 HITech-AI 组织仓库，制定代码规范，引导社员通过 PR 参与开源协作。

常规活动

  • 技术分享会：每周/双周一次，主题覆盖 AI 通识、Agent 入门、GitHub 与开源、实用工具栈。
  • 动手实践：从"跑通第一个 Demo"到"做一个能展示的小作品"，边学边做。
  • 项目开发：HIT-CampusAI 等项目的迭代会议，按模块认领任务。
  • 技术答疑：在社团群内解答编程、环境配置、报错等问题，互助排错。

在做的项目

技术部目前主导和推进以下项目与活动，按"讲座 → 训练营 → 项目"的节奏由浅入深展开：

  • HIT-CampusAI（校园新生问答 Agent）：面向高考后了解学校与新生入校咨询的高频问题，以飞书校园资料、学院介绍、招生与迎新问答为知识库起点，用 Python + Streamlit + FAISS 搭建可问答的小应用，回答不了的问题给出原始入口或人工渠道。计划 2027 年 3~5 月完成约三个月的试用版本。
  • agent-bootcamp（Python + Agent 训练营）：六至八周集中补齐编程与实践基础，参考 Python 入门资料与 Hello-Agents 教程，采用讲解/录播 + 练习 + 集中答疑方式；分导学（Python 基础、Git、环境）、基础（模型调用、提示与上下文、工具函数）、实战（资料检索与 RAG，制作简单 Agent）三阶段，已有基础的成员直接参与实战或帮助同伴。
  • HITech-AI 组织仓库规范：维护 GitHub 组织 下的仓库结构，制定 README、Issue、PR 与代码规范，引导社员通过 PR 参与开源协作；docs 为文档库（科普、教学、活动归档），projects 为项目库。
  • GitHub 信息检索 Agent：按需求检索仓库，整理 README、Releases、使用条件与链接，作为中期原型推进。
  • 系列讲座（2026 秋）：首场"GitHub 与 AI Agent 入门"（110~120 分钟），后续接 GitHub 协作/Skill 与 Agent 案例、AI 工具应用与原理科普、AI 辅助编程与调试，面向全校开放。
建设重点：吸引并支持一批能持续带课、带项目、带新的技术骨干；正式入部按提前公布的量化任务验收（资源卡、运行示例、修改组件或协作记录）。

成员收获

工程能力
从写 Demo 到维护真实开源项目，熟悉 Git、协作流程、代码规范。
项目经验
有一个可写进简历、可演示的开源项目，而不是只跑过教程代码。
技术视野
通过分享会和项目实战，建立对 AI 技术栈的整体认知。

如何加入

不需要你是技术大佬——只要对 AI 技术感兴趣、愿意动手尝试，哪怕从零开始也欢迎。有编程基础更好，没基础可以从学 Git、跑通第一个 Demo 开始。

  • 在 GitHub 给 HITech-AI 组织 点 star，关注仓库动态。
  • 到社团活动咨询群找技术部负责人，申请参与项目或分享会。
  • 想认领项目模块的，直接在对应仓库提 issue 说明你想做什么。
