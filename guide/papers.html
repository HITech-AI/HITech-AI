怎么找资料与论文

找论文不是漫无目的地翻——先确定方向，再用工具精准检索，最后判断值不值得精读。

常用检索入口

  • arXiv：AI 论文的首发平台，几乎所有大模型论文都先挂在 arXiv。按类别浏览（cs.CL 自然语言处理、cs.CV 计算机视觉、cs.AI 人工智能），或用关键词搜索。
  • Google Scholar：学术搜索引擎，按引用次数排序，能看到一篇论文被谁引用了。适合找"这个领域最经典的论文"。
  • Semantic Scholar：AI 驱动的学术搜索，能自动生成论文摘要、梳理引用关系网，还能看到"这篇论文解决了什么问题"。
  • Papers with Code：论文 + 代码的结合体。每篇论文附带开源实现和排行榜，适合想动手复现的人。

检索技巧

  • 关键词组合：用中英文关键词交替搜索。比如搜 "RAG" 的同时也搜 "检索增强生成"，能找到中文综述和教程。
  • 按引用和年份筛选：先看高引用（>1000）的经典论文建立基础，再看近一年（2025–2026）的新论文了解前沿。
  • 顺藤摸瓜：找到一篇好论文后，看它的"Related Work"（相关工作）和参考文献列表——这是该方向最核心的论文集。
  • 判断值不值得读：先看标题 → 摘要 → 关键图。如果三部分看完你觉得"这跟我要做的事有关"，再精读；否则直接跳过，不要有心理负担。

怎么读一篇论文（三遍法）

读论文不需要从头到尾逐字读。推荐"三遍法"，每遍目标不同，时间投入递减：

遍数时间读什么目标
第一遍 · 快速浏览5–10 分钟标题、摘要、引言、图表、结论了解这篇论文在做什么、用了什么方法、效果如何。判断要不要进入第二遍。
第二遍 · 精读1–2 小时方法部分、实验设置、主要结果图表理解方法的核心思路和关键实验。忽略数学推导细节（除非你要复现）。
第三遍 · 复现级数小时–数天完整推导、代码实现、消融实验目标是从零复现。适合深入研究或要做相关项目时。
跳过策略：相关工作（Related Work）通常可以跳过；数学推导如果当前用不到，可以先标记"以后再看"；附录里的细节一般不用读。读论文的目的是获取你需要的信息，不是把论文背下来。

论文阅读与笔记工作流

好记性不如烂笔头：读一篇论文就该留下一篇可复用的笔记。社团鼓励用 Markdown 沉淀，并联动 docs 文档库。

笔记模板

每篇论文笔记建议包含以下结构：

  • 标题与链接：论文标题、作者、arXiv 链接、发表日期。
  • 一句话总结：这篇论文解决了什么问题？（强迫自己用一句话说清）
  • 背景与动机：为什么要做这件事？之前的方法有什么不足？
  • 方法核心：他们提出了什么方法？用最朴素的话解释，不要复制论文术语。
  • 关键结果：在什么数据集上？比之前好多少？（列 2–3 个最重要的数字）
  • 我的想法 / 可复现点：这篇论文对我有什么用？有没有可以复现的实验？局限性是什么？

管理方式

  • 本地 + GitHub 同步：在本地建一个论文笔记文件夹，用 Markdown 写笔记，定期 push 到 GitHub 仓库。这样笔记永远不会丢，也方便分享。
  • AI 辅助做科研简报：把论文 PDF 丢给 AI 对话工具，让它按上面的模板生成初稿，你再修改补充——这比从零写快得多，但一定要自己核对，AI 可能会编造内容。
  • 阅读深度分级：
深度适用场景投入
泛读了解一个方向在做什么、跟谁聊都能接上话每篇 10–15 分钟
精读要做相关项目、需要借鉴方法每篇 1–2 小时 + 笔记
复现要做深入研究、竞赛或论文写作每篇数小时到数天 + 代码

入门推荐论文主题

如果你是第一次读论文，建议从以下主题入手——这些论文相对好读、影响大、和社团方向贴近：

  • Transformer 架构：《Attention Is All You Need》——理解现代大模型的基石。虽然是 2017 年的论文，但几乎所有后续工作都建立在它之上。
  • RAG（检索增强生成）：《Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks》——理解为什么需要"先查资料再回答"。
  • Agent 范式：《ReAct: Synergizing Reasoning and Acting in Language Models》——理解 Agent 如何"边想边做"。
  • 提示工程：《Chain-of-Thought Prompting Elicits Reasoning in Large Language Models》——理解"让模型一步步思考"为什么有效。
  • Embedding 与向量检索：理解 RAG 的底层技术，为什么文本可以被转成向量并做相似度搜索。

找到这些论文的方法：在 Google Scholar 或 Semantic Scholar 搜论文标题，优先看有开源代码的版本。
