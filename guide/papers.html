怎么找资料与论文

从哪找、用什么关键词、怎么判断一篇论文值不值得读——这里给出方法骨架：

【待补充】检索方法

建议写入：

  • 入口：Google Scholar、arXiv、语义检索工具、各方向顶会（见 术语与会议速查）。
  • 技巧：怎么用中英文关键词、怎么按引用与年份筛选、怎么顺藤摸瓜找相关工作。
  • 判断：先看标题 / 摘要 / 图，决定要不要精读。

怎么读一篇论文

【待补充】精读方法

建议给出：读论文的顺序（摘要 → 引言 → 方法 → 实验），每部分的阅读目标；哪些段落可以直接跳过。

论文阅读与笔记工作流

好记性不如烂笔头：读一篇论文就该留下一篇可复用的笔记。社团鼓励用 Markdown 沉淀，并联动 docs 文档库。
【待补充】笔记模板与工作流

建议提供：

  • 一篇论文笔记的模板：背景 → 方法 → 结果 → 我的想法 / 可复现点。
  • 管理方式：本地文件夹 + GitHub 同步，或用 AI 辅助做"科研简报"。
  • 阅读深度分级：泛读 / 精读 / 复现，各适合什么场景。
