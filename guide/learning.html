三条学习路线

以下三条路线属于个人长期型社团活动：可自选一条，在社团内找学习搭子组队，部门提供答疑与支持。三条路线不是互斥的——入门阶段建议先从"Agent 应用线"获得正反馈，再根据兴趣向"Python 工程线"或"ML/DL 理论线"深入。

路线一：Agent 应用线（自顶向下，最快上手）

从用 AI 工具和搭建 Agent 应用开始，遇到问题再下沉到模型原理。适合想快速做出作品、对"AI 能做什么"好奇的同学。

阶段内容可完成练习预计时长
导学Python 基础、文件读写、GitHub 协作、运行环境运行示例、整理资源卡、提交学习记录1–2 周
基础模型调用 API、提示工程与上下文、工具函数、Skill 编写亲手编写/修改一个工具函数2–3 周
实战资料检索与 RAG，制作一个简单 Agent交付可运行小作品，附来源与使用说明约 3 周

推荐资源：hello-agents 教程（Datawhale 出品，Agent 应用 → 大模型 → PyTorch 逐层下沉）。社团 Agent 训练营（参考 rCore 训练营模式，Python + Agent，六到八周）即沿此路线设计。

路线二：Python 工程线（自底向上，打牢代码功底）

从 Python 编程和工程实践起步，逐步过渡到 ML 工程化。适合计算机/电气/大数据等有编程基础或想系统补工程能力的同学。

阶段内容可完成练习预计时长
Python 基础语法、数据结构、函数、文件读写、异常处理写一个命令行小工具（如文件批量重命名）3–4 周
工程与协作Git/GitHub、Markdown、虚拟环境、依赖管理、Docker 入门向社团 docs 仓库提交一次 PR2–3 周
ML 工程用 scikit-learn 跑通经典模型、数据预处理、模型部署完成一个结构化数据预测项目4–6 周

推荐资源：AI Engineering from Scratch（aieng-zh.cn，自底向上系统课：数学 → ML → DL → LLM → Agent）。

路线三：ML/DL 理论线（学院派，深耕原理）

从数学基础到机器学习、深度学习，系统理解模型原理。适合打算深入科研、读研或参加算法竞赛的同学。

阶段内容可完成练习预计时长
数学基础线性代数、微积分、概率统计——补到能理解 ML 公式手推梯度下降、交叉熵公式4–6 周
机器学习西瓜书核心章节：线性回归、决策树、SVM、集成学习用 numpy 手写一个简单模型6–8 周
深度学习PyTorch 入门、CNN、RNN、Transformer 架构复现一个经典小模型（如 MNIST 分类）8–12 周

推荐资源：LAMDA Lab-RoadMap（AIMA 教材 + Python 基础的学院派路线）。书籍推荐周志华《机器学习》（西瓜书）、李沐《动手学深度学习》。

怎么组队找搭子：选同一条路线的人天然有共同进度。在社团群里说一声"我在走 XX 路线，第 X 周，找搭子"，技术部骨干会帮忙对接。每条路线都有答疑渠道，遇到卡住的地方直接在群里问。

基础知识补全

无论选哪条路线，下面几块基础都值得先有个抓手：

编程

  • Python 基础：变量、条件、循环、函数、列表/字典、文件读写。验收标准：能独立写一个 50 行左右的命令行小工具。
  • 环境管理：会用虚拟环境（venv / conda），知道 pip 装包。
  • 推荐资源：Python 官方教程（中文版）、廖雪峰 Python 教程、Datawhale Python 入门课。

数学

  • 线性代数：向量、矩阵乘法、特征值——补到能看懂 Transformer 里的矩阵运算即可。
  • 概率统计：概率分布、期望、贝叶斯——理解模型为什么用交叉熵损失。
  • 微积分：偏导、链式法则——理解梯度下降。
  • 建议：不用系统学完整本教材，结合 ML 课程遇到什么补什么。

机器学习

  • 理解"训练/验证/测试"的基本概念，知道什么是过拟合、欠拟合。
  • 会用 scikit-learn 跑通一个经典分类/回归任务。
  • 对应 Agent 训练营基础阶段：模型调用、提示与上下文、工具函数/Skill。

协作

  • GitHub 基本操作：注册、创建仓库、commit/push、Issue、PR。详见协作与合作。
  • Markdown 写作：能写基本标题、列表、代码块、表格。

用 AI 辅助学习

AI 可以是学习路上的"贴身助教"：帮你解释概念、定位报错、整理笔记、生成练习。下面是社团成员亲测好用的工具类型：

通用对话助手
豆包 / DeepSeek / Kimi
解释概念、翻译、写文案、头脑风暴。用法：把不懂的概念贴给它，让它用"给高中生讲"的方式解释一遍。
AI 编程助手
Cursor / GitHub Copilot / 豆包编程
写代码、解报错、生成代码注释。用法：遇到报错先把错误信息贴给它，让它解释原因并给出修复建议。
AI 检索与资料整理
Kimi / 豆包联网搜索
长文档总结、资料检索、对比不同工具。用法：把论文 PDF 或长文档丢给它，让它提炼摘要和关键结论。
AI 画图与汇报
豆包画图 / 即梦 / Canva AI
生成海报、示意图、PPT 配图。用于活动宣传和作业汇报。
使用原则：AI 是助教不是代笔。让它帮你解释和排查，但不要直接让它写完作业——否则你永远学不会。把 AI 的回答拿去验证、追问"为什么"，才是正确用法。
