模型与架构

缩写 / 英文中文一句话解释
LLM大语言模型Large Language Model——基于海量文本训练的、能理解和生成语言的大模型，如 GPT、Llama、Qwen。
TransformerTransformer 架构当前几乎所有大模型的基础架构，核心是"自注意力机制"，让模型能同时关注输入中所有词的关系。
Token词元 / 令牌模型处理文本的最小单位。一个汉字大约是 1–2 个 token，模型按 token 计费和计算上下文长度。
Embedding嵌入 / 向量表示把文本（或图像）转换成一组数字向量，语义相近的内容向量距离也近。是 RAG 和语义搜索的基础。
Vector DB向量数据库专门存储和检索向量的数据库（如 FAISS、Milvus、Chroma），用于 RAG 中"根据语义找相关资料"。

应用与范式

缩写 / 英文中文一句话解释
Agent智能体能自主规划任务、调用工具、完成多步工作流的 AI 程序。不只是聊天，而是"会干活的助手"。
RAG检索增强生成Retrieval-Augmented Generation——让模型在回答前先从你的知识库中检索相关资料，再基于资料生成回答。解决幻觉和私有数据问题。
Prompt提示词你给模型的输入指令。写好 Prompt 是用好大模型的基本技能——"你怎么问，决定它怎么答"。
Few-shot / Zero-shot少样本 / 零样本Few-shot：在 Prompt 里给几个例子让模型学习；Zero-shot：不给例子直接让模型做。
Chain-of-Thought思维链CoT——让模型"一步步思考"，在回答前先写出推理过程，显著提升复杂推理任务的准确率。
Tool Use工具调用让模型能调用外部工具（搜索、计算器、代码执行、API）来完成任务，是 Agent 的核心能力之一。
MCP模型上下文协议Model Context Protocol——一种标准化协议，让大模型能统一连接外部数据源和工具，减少重复集成。
Skill技能 / 插件封装好的可复用能力模块，让 Agent 能执行特定任务（如搜索、画图、文件处理）。

训练与微调

缩写 / 英文中文一句话解释
Pre-training预训练在海量数据上训练模型的基础能力，是最昂贵的阶段。一般个人和社团不做预训练。
SFT监督微调Supervised Fine-Tuning——在预训练模型基础上，用人工标注的"问答对"进一步训练，让模型学会按特定格式回答。
RLHF人类反馈强化学习Reinforcement Learning from Human Feedback——让人类对模型的回答打分，模型根据反馈优化，让输出更符合人类偏好。
Fine-tuning微调在已有模型基础上，用特定数据继续训练，让模型适应特定任务或领域。比预训练便宜得多。
LoRA低秩适配Low-Rank Adaptation——一种高效微调方法，只训练少量参数，大幅降低微调成本和显存需求。

工程与协作

缩写 / 英文中文一句话解释
API应用程序接口你通过 API 调用大模型服务（如豆包、DeepSeek 的 API），不用自己部署模型。
vibe coding氛围编程 / AI 辅助编程用自然语言描述需求，让 AI 生成代码，人主要负责描述和验证。社团做互动科普作品时常用。
PR拉取请求Pull Request——在 GitHub 上给别人的项目贡献代码的方式，经过 review 后合并。
Docker容器化把应用和依赖打包成一个"容器"，保证在任何机器上都能跑。解决"我电脑上能跑，你电脑上跑不了"的问题。

会议与期刊速查

了解 AI 领域的主要学术会议，方便跟踪前沿和（未来）投稿：

会议 / 期刊领域说明
NeurIPSAI 综合神经信息处理系统大会，AI 领域最顶级会议之一，每年 12 月左右。
ICMLAI 综合国际机器学习大会，与 NeurIPS 并列，每年 7 月左右。
ICLRAI 综合学习表征国际会议，大模型和 Transformer 方向的热门会议。
AAAI / IJCAIAI 综合综合性 AI 会议，覆盖面广，投稿量巨大。
CVPR / ICCV / ECCV计算机视觉视觉方向三大顶级会议。CVPR 每年 6 月，ICCV 奇数年。
ACL / EMNLP / NAACL自然语言处理NLP 方向三大会议。ACL 是旗舰，大模型论文常见。
对入门者的建议：不需要一开始就关注会议。先读 arXiv 上的预印本，等有了明确方向和项目经验后，再去看对应会议的论文集。
