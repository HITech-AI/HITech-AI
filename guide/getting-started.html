我们怎么帮你入门

"智启新航"AI 研学社不搞"包办教学"，而是扮演点火者：每场活动起个头、点燃兴趣、指明方法与路径，后续由你自主研究学习。你只需带着热情来，剩下的路我们指给你看。

我们的入门逻辑很简单：用起来 → 学进去 → 做出来。先把 AI 工具用起来解决一个真实小问题，在这个过程中自然产生"为什么会这样"的疑问，再带着问题去补理论、读论文，最后做出一个能展示的作品。反过来从公式和教材啃起，往往坚持不到第二周。

加入社团你能获得：朋辈搭子（一起学、一起做项目的人）、活动与讲座（双周技术分享、Agent 训练营、学期黑客松）、答疑与指导（技术部先学后教、学长经验分享）、开源协作机会（GitHub 组织 HITech-AI 上的文档与项目）、以及对外合作通道（Datawhale 高校行、企业开源组织活动）。

三步路径：跑通 Demo → 参加活动 → 认领任务

我们建议每个新人按下面三步走，大约四周内完成：

第一步 · 第 1 周
跑通第一个 AI Demo
用一个对话式 AI 工具（如豆包、DeepSeek、ChatGPT 均可），完成一个你真实需要的小任务：比如让它帮你写一段课程介绍、整理一份读书笔记、或生成一个个人主页的 HTML。目标不是做出多漂亮的东西，而是亲手体验"AI 能帮我干活"。
第二步 · 第 2–3 周
参加一次社团活动
推荐从首场活动《GitHub 与 AI Agent 入门》开始：学会注册 GitHub、创建仓库、提交 commit/push，并用 AI Agent 辅助完成一次开源协作。这是社团所有后续活动的共同语言。活动后你会拿到一个可运行的小作品和 GitHub 证书。
第三步 · 第 4 周
认领一个小任务
正式入部采用量化任务验收：从以下任务中选一个完成——整理一张"AI 工具资源卡"（工具名 + 用途 + 上手方式）、运行一个示例项目并写一段运行笔记、或向社团 docs 仓库提交一次 PR（修正一个链接、补充一段说明）。完成后登记到部门台账，即正式成为社团成员。
第一个小项目推荐：用 AI 工具做一个"校园 AI 问答小助手"。参考社团门面项目 HIT-CampusAI（校园 AI 生活助手，技术栈 Python + Streamlit + FAISS + 大模型 API）。你不需要一开始就复刻它——先用 AI 对话工具把"校园 FAQ 问答"的逻辑跑通，再考虑把它做成网页。

环境准备

开始之前，把下面几样东西准备好，后续活动都用得上：

  • 一台能上网的电脑：Windows / macOS 均可。不需要高性能显卡——入门阶段用云端 API 和 Colab 就够。
  • 一个 GitHub 账号：到 github.com 注册，昵称建议用真名或常用 ID，方便后续协作认人。
  • 一个 AI 对话工具：豆包、DeepSeek、Kimi、ChatGPT 任选其一，能正常对话即可。
  • 加入交流群：关注社团宣传部通知，扫码进入微信/QQ 交流群，活动信息和招新都在群里发布。
  • （可选）Python 环境：如果打算做 Agent 训练营或项目，装一个 Python 3.10+ 和 VS Code。零基础可以先不装，等训练营导学阶段跟着一起配。

新生 FAQ

零基础能加入吗？会教我吗？

能。社团的定位就是"面向全校的 AI 入门实践"，摸底问卷显示多数成员入学时也是"会一点/在学"的水平。首场活动就是零基础友好的，技术部采用"先学后教"模式——骨干成员先学一步，再带着大家做。你不需要预先会编程。

参加社团要交钱吗？每周要投入多少时间？

不收费。社团活动本身不涉及任何收费项目（与 Datawhale 合作的活动也是免费的）。建议每周投入 3 小时以上，主要用于参加活动和做练习；如果加入 Agent 训练营或项目组，会相应多一些，但时间完全由你自己安排。

我没有电脑 / 不会编程怎么办？

没有电脑也能参加讲座和研讨活动；动手实践环节建议用自己的电脑。不会编程完全没关系——入门阶段用 AI 对话工具就能完成很多任务，Python 编程在 Agent 训练营的导学阶段会从零开始教。

怎么找到一起学习、做项目的搭子？

参加活动后在群里主动说一声"我在学 XX，想找搭子"，通常能找到同方向的人。社团也鼓励按学习路线组队——选同一条路线的人天然有共同进度。

社团会组织比赛、黑客松吗？

会。学期末组织内部黑客松，围绕已有项目（如 HIT-CampusAI、GitHub 信息检索 Agent）做成果展示。外部比赛由实践部核实当期通知（如校内 Agent AI 赛事、动感地带 AI+高校创制计划等），技术部判断作品是否匹配后组织报名。

入部后发现不适合怎么办？

社团是开放平台，成员因时间或兴趣变化退出属正常情况，不必有压力。正式入部按任务验收通过后加入，之后也可自愿退出。

加入社团与参与方式

正式入部采用提前公布的量化任务验收：完成对应小任务（如整理一张资源卡、运行一个示例、提交一次协作记录）后即可加入。公布完成要求、联系人与补交办法。

具体流程：

  1. 关注通知：加入微信/QQ 交流群，留意宣传部发布的活动通知和招新公告。
  2. 参加首场活动：参加《GitHub 与 AI Agent 入门》或 Datawhale《AI 新手村》高校行活动，现场完成一个小 demo。
  3. 完成入部任务：在群里领取量化任务清单（资源卡 / 运行示例 / 协作记录三选一），按要求完成。
  4. 登记验收：将成果链接登记到部门台账，技术部验收通过后正式入部。
  5. 选择部门：入部后可根据兴趣选择部门——技术部（学技术做项目）、实践部（对接外部资源）、宣传部（做内容传播）、研讨部（做深度调研讨论）。
