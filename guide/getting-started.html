我们怎么帮你入门

研学社不搞"包办教学"，而是扮演点火者：每场活动起个头、点燃兴趣、指明方法与路径，后续由你自主研究学习。你只需带着热情与基础来，剩下的路我们指给你看。

【待补充】入门理念展开

用 2–3 段话讲清研学社的入门理念："点火式引导""朋辈互助""用起来 → 学进去 → 做出来"。

可附：加入社团能获得什么（活动、资料、搭子、项目、答疑）。

第一步：先动手做一个小项目

与其先啃理论，不如先做一个能看到结果的小项目，建立正反馈。下面为你预留了第一个项目的位置：

【待补充】第一个 AI 项目

推荐一个面向零基础、能在一场活动内完成的小项目，例如：用 AI 工具做一个"AI 入门问答小助手"，或检索并整理一个你感兴趣的 GitHub 项目。

给出：项目目标 → 用到什么工具 → 大概步骤（3–5 步）→ 完成标准。

新生 FAQ

把新生问得最多的问题集中在这里，持续更新。以下是小节骨架：

【待补充】FAQ 列表

用"问 → 答"的方式列 8–15 个高频问题，例如：

  • 零基础能加入吗？会教我吗？
  • 参加社团要交钱吗 / 每周要投入多少时间？
  • 我没有电脑 / 没有编程基础怎么办？
  • 怎么找到一起学习、做项目的搭子？
  • 社团会组织比赛、黑客松吗？

加入社团与参与方式

正式入部采用提前公布的量化任务验收：完成对应小任务（如整理一张资源卡、运行一个示例、提交一次协作记录）后即可加入。公布完成要求、联系人与补交办法。
【待补充】招新与加入流程

写明：招新时间与负责人 → 报名入口（群 / 问卷）→ 入部任务与验收标准 → 常见答疑入口。
