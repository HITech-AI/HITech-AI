活动归档

把每一场活动沉淀下来，让走过的路有迹可循。以下是已计划和已完成的活动：

  • 《GitHub 与 AI Agent 入门》（2026 秋，首场对外公开活动）—— 与 Datawhale《AI 新手村》高校行融合，150 分钟线下实操。内容：认识 AI 与 Agent、GitHub 注册与基本操作、用 AI Agent 辅助完成一次开源协作。产出：每人完成一个 AI 小作品 + GitHub 仓库。
  • Datawhale AI+X 高校行 · 哈工大场（2026 秋，计划 11 月落地）—— Datawhale 提供教程、物料和嘉宾支持，社团提供场地和组织。完成者获 Datawhale 证书。
  • 研讨部双周研讨（2026 秋持续）—— 第一学期四期议题：AI 重构就业、无用阶级争议、个人不可替代性、AI 对生产关系变革。每次 90 分钟，含技术实证环节。
  • Agent 训练营（2027 春，计划）—— 六到八周，分导学、基础、实战三阶段。产出：每人交付一个可运行的小作品。
  • 学期黑客松（2027 春末，计划）—— 围绕 HIT-CampusAI 等项目做成果展示和迭代。

完整活动归档见 docs 活动归档。

技术博客与经验

社团鼓励成员把学习过程中的思考和经验写成文章。每学期征集简短方法论思考，经本人同意后在社团渠道分享。

  • 学习总结：学完一门课或一个方向后，写一篇"我是怎么学的"。
  • 项目复盘：做完一个项目后，记录做了什么、遇到什么坑、怎么解决的。
  • 踩坑记录：环境配置、报错排查、工具使用——这些"小事"对下一个人特别有用。
  • 方法论思考：按"问题 → 方法 → 验证 → 限制 → 个人判断"的结构写。这是社团特别鼓励的产出形式。

博客文章将沉淀在 docs 仓库的博客目录中，优秀文章由宣传部推荐到公众号和 B 站。

AI 时代行业观察

研讨部的常规产出：把每次研讨结论整理成《AI 时代行业观察》小册子——AI 对生产关系、就业环境、岗位结构的分析与观察，落回一句话："这对我们这批人有什么用？"

研讨部第一学期四期议题的产出将汇总为《AI 时代行业观察》第一辑：

  • 议题一：AI 会怎样重构就业？——产出岗位替代调研小报告。
  • 议题二："无用阶级"是危言耸听吗？——产出 AI 能力边界清单。
  • 议题三：大模型时代，个人的不可替代性从哪来？——产出个人竞争力分析模板。
  • 议题四：AI 对生产关系的变革——产出行业观察案例集。

每期研讨纪要（事实 + 观点 + 分歧 + 共识）会在研讨部归档中发布。

研究社区与外部动态

关注外面的研究社区与技术动态，让视野不被社团围墙限制：

  • Datawhale：国内活跃的开源学习社区，有完善的课程体系和高校行活动。datawhale.club
  • Hugging Face 博客：最新的模型发布、教程和技术解读。huggingface.co/blog
  • arXiv cs.CL / cs.CV：最新论文预印本，每周刷一次标题就能跟上前沿。
  • Papers with Code：论文 + 代码 + 排行榜，看哪个方向最活跃。paperswithcode.com
  • 国内 AI 动态：关注 Qwen（通义千问）、DeepSeek、智谱等国产大模型的开源动态。
