# HITech-AI

> **"智启新航"AI 研学社 · 开源组织** · 以 AI 启航，向新知远行

HITech-AI 是"智启新航"AI 研学社的 GitHub 开源组织。社团以**朋辈互助与 AI 研学**为核心，帮助成员正确认识、合理使用人工智能，共同探索 AI 时代下的成长方向。

无论是否具备技术基础，都能在这里找到适合自己的方向——用起来，学进去，做出来。

## 主题内涵

"智启新航"——以智能科技（AI）启迪智慧，开启学习与成长的新航程：

- **智** · 以 AI 启迪智慧，激发创新思维
- **启** · 开启、启发，推动迈出 AI 学习与实践的第一步
- **新航** · 新征程、新起点，驶向新知与未来

## 四部门

| 部门 | 主要职责 | 能力导向 |
|------|----------|----------|
| **实践部** | 对外交流、实践活动、校企研学 | 增强规划力 |
| **宣传部** | 活动宣传、文案编辑、海报设计、新媒体运营 | 增强吸引力 |
| **研讨部** | 主题调研、读书分享、圆桌讨论、资料整理 | 增强信息力 |
| **技术部** | AI 原理科普、AI 工具教学、企业 AI 应用解析 | 增强工程力 |
